About this map

Buildings

Building footprints from GlobalBuildingAtlas (Zhu et al., TU Munich):

  • Footprints: OpenStreetMap + Microsoft ML footprints (ODbL license) merged with Google Open Buildings (CC BY 4.0)
  • Heights: GBA LoD1 height model (CC BY-NC 4.0 — non-commercial use only)
  • 3D detail: OpenStreetMap buildings (© OpenStreetMap contributors) rendered for visual detail where GBA data exists; all popups show GBA-derived data
  • Coverage varies: some rural provinces have incomplete footprints (flagged with ⚠)

Population estimates

Each building shows an estimated resident range from two sources:

  • WorldPop 2027 (worldpop.org, CC BY 4.0): UN-calibrated 100m gridded projection, summed per province
  • DOPA 2025 (dopa.go.th): official Thai registered residents per province

Methodology

Each province's total is split among its buildings proportional to footprint area × floors, where floors = max(1, round(height ÷ 3)) (3m per story; 1 if no height data).

This is a dasymetric estimate: bigger and taller buildings get more people. Caveats:

  • Assumes all floor space is residential (offices/shops inflate numbers)
  • WorldPop tends higher (counts daytime/unregistered); DOPA tends lower (registered only)
  • True occupancy varies — treat as an order-of-magnitude guide, not a census
